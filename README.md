## 📌 About the Project

**BargainCart** is a modern, responsive, and feature-rich **full-stack e-commerce and rental web application** built using **React.js and Firebase**.

The platform combines online shopping with an interactive **AI Bargaining Assistant**, allowing users to negotiate product prices within predefined smart limits before checkout.

BargainCart also provides a dedicated rental store, KYC verification, real-time order and rental tracking, secure authentication, multi-step checkout, Prime Membership, wallet/gift card support, and a comprehensive real-time Admin Dashboard.

# 💻 How to Run Locally

Follow these steps to run BargainCart on your local machine.

## 1. Clone the Repository

```bash
git clone https://github.com/mohdmujtabanizami/bargaincart-app.git
cd bargaincart-app
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Configure Firebase

Create or update your Firebase configuration file, for example:

```text
src/firebase.js
```

Add your Firebase project credentials:

```javascript
import { initializeApp } from "firebase/app";
import { getAuth, GoogleAuthProvider } from "firebase/auth";
import { getDatabase } from "firebase/database";

const firebaseConfig = {
  apiKey: "YOUR_API_KEY",
  authDomain: "YOUR_AUTH_DOMAIN",
  databaseURL: "YOUR_DATABASE_URL",
  projectId: "YOUR_PROJECT_ID",
  storageBucket: "YOUR_STORAGE_BUCKET",
  messagingSenderId: "YOUR_MESSAGING_SENDER_ID",
  appId: "YOUR_APP_ID"
};

const app = initializeApp(firebaseConfig);

export const auth = getAuth(app);
export const googleProvider = new GoogleAuthProvider();
export const db = getDatabase(app);
```

> ⚠️ **Security:** Never commit private credentials, API keys, service-account files, or sensitive Firebase configuration to a public repository.

### 4. Start the Development Server

```bash
npm run dev
```

The application will be available on your local development server.
